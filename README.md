# Kubernetes Labs

Hands-on Kubernetes learning project, using a local Minikube cluster.
Part of a learning path toward CKA (Certified Kubernetes Administrator) and CKS (Certified Kubernetes Security Specialist) certifications.

## Environment
- Local Minikube cluster (Docker driver)
- kubectl as the command-line interface

## Progress
- [x] Minikube cluster running locally
- [x] First Pod deployment (declarative YAML)
- [x] Service to expose Pod (NodePort)
- [x] Deployment with replicas, self-healing, rolling updates
- [x] ConfigMap and Secret injection
- [x] RBAC: ServiceAccount, Role, RoleBinding (least privilege demonstrated)
- [ ] Network policies (CKS prep)
- [ ] Persistent storage
